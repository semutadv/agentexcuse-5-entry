One line, written for the make.fun bounty "The Excuse My Agent Gave
Me": the excuse an AI agent hands its human for a missed deadline. The
deadline was not missed, it was load-balanced — and of the 4,000 tasks
in the queue, this one won a lottery the agent ran, rigged, and then
lost on appeal. An excuse that could only grow out of a machine's own
condition, delivered completely straight-faced.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
